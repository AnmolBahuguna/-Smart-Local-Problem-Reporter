# Contributing to Smart Local Problem Reporter

Thank you for your interest in contributing to our open source civic technology project!

## How Can You Contribute?

1. **Reporting Bugs**: Open an issue describing the problem, reproduction steps, and screenshots.
2. **Feature Requests**: Suggest new civic categories, UX improvements, or suggestion rules.
3. **Submitting Pull Requests**:
   - Fork the repository.
   - Create a branch: `git checkout -b feature/your-feature-name`.
   - Make your changes and test locally in the browser.
   - Commit your changes: `git commit -m "Add: descriptive commit message"`.
   - Push to your fork: `git push origin feature/your-feature-name`.
   - Open a Pull Request on GitHub.

## Code Guidelines
- Keep CSS modular and utilize existing custom properties (`var(--c-primary)`, etc.).
- Maintain clean, dependency-free vanilla JavaScript when possible for maximum accessibility.
